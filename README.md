# Endometriose em Foco

Homepage responsiva em HTML/CSS/JavaScript, com referências científicas e espaço reservado para o GIF anatômico.

## Incluir o GIF

1. No GitHub, entre no repositório e clique em **Add file > Upload files**.
2. Envie o arquivo do pacote ZIP em `endometriose-em-foco/assets/anatomia.gif` para o caminho **`assets/anatomia.gif`** (crie a pasta `assets` se necessário).
3. Confirme o commit. O arquivo `index.html` já aponta para esse caminho.

## Visualizar

Após os arquivos estarem no repositório, em **Settings > Pages** selecione **Deploy from a branch** e escolha `main` e `/ (root)`. O GitHub Pages gerará o endereço público.

Conteúdo educativo, não substitui orientação médica. Referências: OMS, ESHRE, NICE e PubMed.
